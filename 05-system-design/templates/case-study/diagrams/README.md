# Diagrams

For each diagram, commit both files:

- **Editable source:** `<name>.drawio` ([draw.io / diagrams.net](https://app.diagrams.net)) or `<name>.excalidraw` ([Excalidraw](https://excalidraw.com))
- **PNG export:** `<name>.png`, which is what the Markdown files embed, since GitHub can't render the editable formats

Expected names: `legacy-architecture` and `target-architecture`. Add others as needed, e.g. `data-flow`.

Re-export the PNG whenever you edit the source. Don't show real client names, account IDs or hostnames.
